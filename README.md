# Nano Banana — плагин для DeepSeek Harness

Генерация и правка изображений моделями Google Gemini (Nano Banana 2 / 2.1 / Pro /
Lite / 2.5 legacy) прямо из чата: промпт или пути к референсам, выбор модели и
разрешения 1K–4K. Картинка сохраняется в рабочую папку сессии и показывается в
ответе.

Плагин добавляет агенту два инструмента: `nano_banana` (генерация/правка) и
`nano_banana_models` (что доступно ключу).

## Установка

Нужен DeepSeek Harness 0.2.x с профилем (Desktop или `dsh` с `--profile`).

1. Склонируйте репозиторий в постоянную папку:

   ```bash
   git clone https://github.com/aosnafanja/DSH-NanoBanana-plugin.git
   ```

   Приватный репозиторий: сначала `gh auth login` (или настройте SSH-ключ), либо
   просто скопируйте папку на машину любым способом.

2. В DSH откройте **Plugins → Add plugin**, вставьте **абсолютный путь** к папке
   репозитория, нажмите **Install**, затем **Enable now**.

   Если у машины есть доступ к GitHub, вместо пути можно вставить адрес
   `https://github.com/aosnafanja/DSH-NanoBanana-plugin.git`.

3. Добавьте ключ Gemini API (см. ниже) и вызовите инструмент в чате.

Плагин ставится ссылкой на папку: не удаляйте и не перемещайте её после установки.

## Ключ API

1. Получите ключ в Google AI Studio: <https://aistudio.google.com/apikey>.
2. Добавьте его в хранилище учётных данных DSH — файл `~/.dsh/.credentials.yaml`,
   секция `refs` (права на файл должны остаться `600`):

   ```yaml
   refs:
     GEMINI_API_KEY: "AIza..."
   ```

   Плагин читает это имя на каждом вызове, поэтому ключ можно заменить без
   перезапуска. Имя задаётся настройкой `apiKeyEnv`.

Другие способы плагин тоже понимает, но для них нужен ручной слой конфигурации:
переменная окружения процесса DSH с именем `apiKeyEnv` или настройка `apiKey`.

Без ключа инструменты возвращают ошибку с этой же подсказкой.

## Модели

| Алиас | Модель | Когда использовать |
|---|---|---|
| `flash` (по умолчанию) | `gemini-3.1-flash-image` — Nano Banana 2 | быстрые итерации, несколько референсов |
| `2.1` | `gemini-nano-banana-2.1` — Nano Banana 2.1 | рабочий вариант flash-класса, лучше текст и многоходовость |
| `lite` | `gemini-3.1-flash-lite-image` | самое дешёвое и быстрое, без сложных многоходовых правок |
| `pro` | `gemini-3-pro-image` — Nano Banana Pro | сложные инструкции, бренд-консистентность, точный текст на картинке |
| `legacy` | `gemini-2.5-flash-image` — Nano Banana | совместимость со старыми ключами, только 1K |

Разрешения: `1K`, `2K`, `4K`; `512` — только для `gemini-3.1-flash-image`.
Пропорции: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`,
`21:9`, `1:4`, `4:1`, `1:8`, `8:1`.

`nano_banana_models` опрашивает `models.list` и дополняет его каталогом известных
моделей: часть моделей (например, `gemini-nano-banana-2.1`) отвечает на вызовы,
хотя API её не анонсирует — такие строки помечены «not advertised».

Фактические размеры кадра: `1K` ≈ 1 Мп (928×1152 при 4:5), `2K` = 1856×2304,
`4K` = 3712×4608. Формат ответа выбирает модель — обычно JPEG.

Глубина рассуждений (`thinking`): `2.1` — `minimal` / `medium` / `high`,
`flash` и `lite` — только `minimal` / `high`, `pro` и `legacy` настройку не принимают.

## Использование

В чате достаточно описать задачу: «сгенерируй украшение на белом песке» или
«отредактируй `source image/ref.png`: добавь зимний свет». Агент вызывает
`nano_banana` с нужными аргументами:

- `prompt` — что нарисовать или как изменить референсы;
- `references` — пути к PNG/JPEG/WebP (до 14 штук; суммарно около 13 МБ до base64);
- `model`, `size`, `aspect_ratio`, `thinking` — модель, разрешение, пропорции, глубина рассуждений;
- `name`, `path` — имя файла и путь сохранения.

Один вызов — одно изображение; для вариантов нужно несколько вызовов (агент может
запускать их параллельно). Результат пишется в папку сессии
(`outputs/nano-banana` по умолчанию), путь возвращается агенту, а картинка
показывается в чате. Последующее чтение файла не требуется.

## Настройки

| Ключ | По умолчанию | Значение |
|---|---|---|
| `apiKey` | пусто | ключ Gemini API напрямую (проще держать его в `refs`) |
| `apiKeyEnv` | `GEMINI_API_KEY` | имя ключа для хранилища учётных данных / окружения |
| `baseUrl` | `https://generativelanguage.googleapis.com` | корень API (прокси — сюда) |
| `defaultModel` | `flash` | алиас или полный id модели |
| `defaultSize` | `2K` | `512`, `1K`, `2K`, `4K` |
| `defaultAspectRatio` | пусто | модель решает сама |
| `defaultThinking` | пусто | уровень рассуждений, если модель его принимает |
| `outputDir` | `outputs/nano-banana` | папка относительно рабочей папки сессии |
| `requestTimeoutMs` | `240000` | таймаут одного запроса |

Настройки живут в `config` строки `nano-banana` в [`cordis.patch.yml`](cordis.patch.yml);
после правки плагин перезагружается сам.

## Ограничения

- Каждый вызов — платный запрос к Gemini API; `pro` и `4K` заметно дороже.
- Промпт и все референсы отправляются в Google; на выходе картинка с водяным знаком SynthID.
- Суммарный бюджет референсов — около 13 МБ сырых байт (лимит inline-запроса
  Gemini ≈ 20 МБ вместе с base64), поэтому 3–4 крупных 2K-референса уже могут
  не пройти; уменьшайте файлы или отправляйте их по одному.
- Превью в чате ужимается хранилищем вложений: для 4K картинка показывается
  уменьшенной, в результате это помечается как «preview downscaled».
- Имена файлов из кириллического промпта транслитерируются; если транслит пуст,
  берётся `nano-banana`.
- Существующий файл не перезаписывается: при совпадении имени добавляется
  суффикс `-2`, `-3` и так далее, а в результате возвращается реальный путь.
- Плагин пишет только в рабочую папку сессии; заданный моделью `path` за её
  пределами отклоняется.

## Структура

| Файл | Назначение |
|---|---|
| `index.js` | регистрация инструментов, пути, запись файлов, тексты результата |
| `gemini.js` | алиасы моделей, разрешения и пропорции, HTTP-клиент, разбор ошибок |
| `cordis.patch.yml` | строка плагина и значения по умолчанию |
| `locale/*.json` | название и описание для страницы Plugins |
| `icon.svg` | иконка плагина |
